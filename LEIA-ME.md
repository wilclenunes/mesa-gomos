# Como continuar com o Claude Code

1. Descompacta esta pasta no teu computador (por exemplo em `Documentos/mesa-gomos`).
2. Abre o `index.html` com duplo clique para veres o simulador no navegador.
3. Abre o terminal nessa pasta e escreve `claude` para iniciar o Claude Code.
4. O Claude lê automaticamente o ficheiro `CLAUDE.md`, que explica o projeto.
5. Pede mudanças em linguagem normal. Exemplos:
   - "Muda a mesa para 45 cm de diâmetro e 20 gomos por gaveta."
   - "Usa esta fotografia de tecido como textura do bouclé natural."
   - "Faz uma animação de um gomo a sair e a voltar a encaixar."
   - "Adiciona um botão para abrir as gavetas."
6. Depois de cada mudança, atualiza o navegador (F5) para veres o resultado.
